# Créditos

**Ecos da Floresta: A Jornada de Lumo**, projeto acadêmico de Game Development.

## Assets

Todos os recursos são originais e foram criados para este projeto. Não há assets de terceiros.

| Recurso | Origem | Licença |
|---|---|---|
| Sprites, tiles, fundos, interface e ícone | Gerados por código em `Assets/Scripts/Editor/Generation/` | Originais do projeto |
| Músicas (5) e efeitos sonoros (13) | Sintetizados por código em `SoundSynth.cs` e `AudioLibrary.cs` | Originais do projeto |
| Fonte | `LegacyRuntime.ttf`, embutida na Unity | Distribuída com a Unity |

## Ferramentas

- Unity 6000.0.76f1
- C# (.NET Standard 2.1)
- Pacotes oficiais da Unity: 2D Sprite, 2D Tilemap, uGUI
